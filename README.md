## 👋 A bit about me

I'm Basit, a software engineer from Islamabad. I graduated with a BS in Computer Science from Abdul Wali Khan University, Mardan, and I've spent the last year turning that degree into real apps.

I work as a Flutter developer at QuickFile, where I write production code and ship features with senior engineers who review it. Before that I did a mobile development internship at Kaizen Hive. On my own time I built Hisab360, a point-of-sale and ledger app that local shopkeepers can run with no internet at all.

Right now I'm moving deeper into AI. I'm learning Python, NumPy and Pandas, and I'm building AI features into real tools, like a Chrome extension that helps write LinkedIn replies. I'm looking for a team where I can keep building mobile products and grow into AI engineering.

## 🤖 How I use AI

I treat AI tools like a fast pair of hands, not a replacement for understanding the code. I decide the architecture and review every change before it goes in.

| Tool | What I use it for |
|---|---|
| **Claude** | Planning architecture, writing structured prompts, reviewing logic and debugging |
| **Gemini** | Running prompt packs inside VS Code to build screens and features quickly |
| **Codex** | Executing code changes and refactors across a project |
| **Muse AI** | Brainstorming ideas and speeding up creative and content work |

This way of working helps me build pixel-accurate UI faster while keeping the code clean and tested.
